## Code Generation Principles

### Full-Stack Specifics:
1. **Backend (FastAPI):**
   - Organize as RESTful endpoints with clear separation of concerns
   - Implement async processing for GPU-heavy operations
   - Use dependency injection for model management
   - Cache models in memory after first load
   - Include comprehensive error handling with meaningful messages
   - Return results as base64 or binary downloads

2. **Frontend (React):**
   - Component-driven architecture (separate concerns into reusable components)
   - Use Tailwind CSS for styling (no inline CSS unless necessary)
   - Implement drag-and-drop file upload
   - Show real-time processing feedback and progress spinners
   - Side-by-side preview with comparison slider
   - Lazy load images to prevent memory bloat
   - Store results in state for quick downloads

3. **Image Processing:**
   - Always preserve original resolution (no downscaling unless user requests)
   - Implement multiple detection strategies and combine masks
   - Return both processed image AND quality metrics (BRISQUE, SSIM)
   - Include optional post-processing (sharpening, denoising)
   - Support multiple output formats (PNG, JPEG with quality control)

4. **Model Management:**
   - Create lazy-loading wrappers to avoid startup delays
   - Implement model discovery API that reports availability
   - Grey out unavailable methods in UI with explanatory tooltips
   - Auto-download missing models on first use
   - Cache loaded models at module level to prevent reloading

### Code Quality Standards:
- No placeholder code or TODOs - everything must be complete and functional
- Comprehensive docstrings for all functions (Google style)
- Type hints for Python (3.12+), TypeScript for React
- Error messages must be user-facing and actionable
- All imports must be pinned to specific versions in requirements.txt
- Include setup instructions in docstrings

### Documentation Requirements:
- README.md with full setup steps
- API endpoint documentation
- Architecture diagram (text-based)
- Method comparison table
- Troubleshooting section
- Example curl commands for all endpoints

## Implementation Strategy

### Phase 1: Backend Foundation
1. Set up FastAPI with async endpoints
2. Implement watermark detection module (FFT + edge + alpha analysis)
3. Integrate removal methods one-by-one (start with OpenCV, then LaMa)
4. Add quality metrics (BRISQUE, SSIM)
5. Create model download/cache infrastructure

### Phase 2: Frontend
1. Build upload component with drag-and-drop
2. Implement preview panel with before/after
3. Add method selection buttons (conditional rendering based on availability)
4. Create comparison slider
5. Add download functionality

### Phase 3: Integration & Refinement
1. Wire frontend to backend
2. Add error handling and retry logic
3. Implement model lazy-loading with status indicators
4. Optimize inference speed
5. Add dark mode and accessibility features

### Phase 4: Deployment
1. Containerize both services
2. Create docker-compose for local development
3. Add GitHub Actions CI/CD
4. Create deployment guides
